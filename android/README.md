# Vertex Demo APK

Android 8.0 or later. The current Android source is **Vertex 1.9-demo, versionCode 13**. The web UI, JavaScript, styles, icons and property photos are bundled inside the APK so the core demo opens without hosting. External links/maps still need internet.

## Build

Use JDK 21, Android SDK platform 35 / build-tools 35.0.0, and Gradle 8.11.1.

```text
gradle -p android assembleDebug
```

Output: `android/app/build/outputs/apk/debug/app-debug.apk`.

## Signing

This project does **not** store the historical private signing key in GitHub. A CI/debug build therefore receives a debug signing certificate generated by the build environment. If a phone already has an older Vertex APK signed with another certificate, Android will reject an in-place update; uninstall the old demo first, then install the new APK.

Package: `com.vertex.demo`  
Version name: `1.9-demo`  
Version code: `13`

## Release checks

Before building, CI runs the Vertex unit/release checks and synchronizes `vertex/dist` into `android/app/src/main/assets/site`. The APK job then verifies package metadata, signature validity, and produces SHA-256 metadata alongside the APK.

This is a demonstration build. Real payments, OTA synchronization, production authentication and OpenAI/LLM access are not enabled by the APK itself.
