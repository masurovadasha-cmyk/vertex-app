# Vertex 1.7-demo — 29 сентября 2026

Vertex 1.7-demo is the stabilization release for the current Uzbekistan demo.

## What is included

- Views owner-confirmed catalog: 6 cards and 16 photos.
- Dated Airbnb reference quotes remain tied only to 12–15 October 2026 for 2 adults.
- Search by Tashkent, Samarkand, Bukhara and Khiva.
- Tashkent directions: NRG U-Tower, Nest One, Boulevard and Gardens Residence.
- Local demo booking requests with date/capacity validation.
- Favorites, trips and owner calendar.
- Local property discussion thread for each listing.
- Owner operations dashboard with request counts, confirmed nights and a clearly labeled local demo report.
- CRM, demo messages/calls and booking-to-CRM handoff.
- Department service requests and guest/staff/admin demo workflow.
- Travel-package builder and persistent local tasks.
- Real Estate request category.
- RU/EN interface, PWA and Android package source.
- Catalog-based voice/demo concierge; no OpenAI connection.

## Safety and truthfulness boundaries

- No real card charges, acquiring, payouts or refunds.
- No real OTA/channel synchronization with Airbnb/Booking.
- No real provider inventory for tickets, cars, tours or restaurants.
- No cross-device account/data synchronization.
- Guest/owner/staff/admin switches are demo roles, not authentication.
- Owner P&L, owner payouts, bank data and tax/accounting data are not connected.
- Service prices are either explicitly illustrative or shown as “Enquire”.
- OLX is not used.
- Vertex JARVIS is not part of this application.

## Release acceptance

The release gate checks JavaScript syntax, CSS parsing, HTML/local resource references, manifests, service-worker asset references, package arithmetic, catalog quote semantics and static release consistency. Android web assets are kept synchronized with the web build while preserving Android-specific service-worker/install behavior.
