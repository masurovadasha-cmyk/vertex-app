# Консьерж: готовность к общему выпуску

Функциональность завершена в общем рабочем каталоге. Не требует API-ключа.

- `vertex/dist/concierge-demo.js`: отдельный чат гостя, RU/EN ответы по каталогу, несколько тем в одном вопросе, актуальный итог корзины, честные границы демо, вывод через textContent.
- `vertex/dist/concierge-learning.js`: синтез речи браузера, включение/повтор/стоп, ручное обучение проверенным ответам, локальная память до 100 записей, удаление, восстановление после перезагрузки. Не выполняет автоматическое обучение модели или обмен памятью между устройствами.
- `vertex/dist/concierge-demo.css`: интерфейс чата и памяти. Подключения добавлены в index.html, файлы внесены в sw.js (cache v5).
- Эти три файла скопированы в Android assets, подключения добавлены в Android index.html. Остальные Android assets этой работой не перезаписывались.
- `MainActivity.java`: TextToSpeech для Android. Запросы через onJsPrompt принимаются только от https://appassets.androidplatform.net; внешний контент не получает JavascriptInterface. Stop при закрытии/паузе, shutdown при уничтожении. Manifest добавляет запрос TTS_SERVICE.

Проверки: `node vertex/tools/concierge-demo.test.cjs` — 12 успешно; синтаксис JS проверен. В браузере проверены ответ о завтраке/прачечной, сохранение исправления, повторное использование, сохранение после reload и управление голосовыми кнопками. Реальный звук не подтверждён на физическом устройстве. Снимок: artifacts/concierge-demo-check.png.

Wrangler dry-run прошёл (23 ресурса на момент запуска). Прямой deploy не выполнен: CLI не авторизован. Получено сообщение другого чата, готовящего общий выпуск, поэтому повторная публикация не запускается. Локальный preview: http://127.0.0.1:8787 .

Попытка Android сборки завершилась AccessDeniedException на build/intermediates/.../R.jar, без Java source diagnostics, и больше не повторяется во избежание параллельных сборок. В этой работе versionCode был поднят с 4 до 5 и versionName с 1.3-demo до 1.4-demo до получения сообщения о координации; финальный номер согласовать владельцу общего выпуска. Файлы консьержа готовы для общей сборки. Нужна проверка TTS и установленного русского/английского голосового пакета на телефоне.
