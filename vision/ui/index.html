ARCHITECTURE

Как собрана VERTEX Vision

01

Vision Core

Identity, организации, роли, permissions и единый tenant boundary.

02

Views Operations

Апартаменты, бронирования, stay lifecycle, check-in/out и внутренняя уборка.

03

PostgreSQL + RLS

Данные и права проверяются сервером; UI не является границей безопасности.

04

Audit + Events

Критические операции пишут audit trail и outbox/domain events.

05

Idempotency

Повтор критической команды не создаёт дубликат операции.

06

Independent Modules

Будущие подразделения подключаются через Core/API/events, а не через чужие таблицы.
