# Vertex 1.13-demo / red-canva1

Исходная версия: `9fe4a4ca988eb2d7f3c28ee740140b12dcaa8a2b`, 1.12-demo. Проверенный код: `be4d4faf3dbe612665ab3d89be541317b90596ac`. Образец: выбранные владельцем четыре экрана Canva DAHWlBDKYlY. Красный акцент заменяет прежнюю песочную/синюю тему, нейтральные поверхности и тёмный текст сохранены.

## Реализовано

- Общий адаптер `brand-red.css`: основные действия, выбранные вкладки, аватары, ссылки, фокус и значки приложения. Фотографии не менялись. Подтверждённые даты сохраняют отдельный зелёный статус с подписью, блокировки — серый.
- `host-icons.js`: общие SVG-иконки без зависимости от шрифта. Повторное декорирование новой консоли отключено.
- Переход из списка объявлений в «Меню» открывает актуальное меню с заработком и аналитикой, а не прежнюю копию.
- Завершившееся проживание исключается из предстоящих по локальной календарной дате, в том числе после полуночи в Ташкенте.
- Раздел заработка показывает все объекты, не первые шесть. Это суммы локальных заявок, а не реальные выплаты.
- Сохранены календарь, переключение месяца/объекта, поиск, редактор локальных объявлений, локальные обсуждения и существующие услуги.
- Обновлены тема браузера, SVG/PNG-значки, service-worker cache, синхронизированы ресурсы Android. Исходники Android: versionCode17.

## Публикация и незакрытые вопросы

Во время работы master обновлён параллельным Host Studio до `205621415a796738f35ab7e4f354eb7c01351c50`. Красная версия пока в отдельной ветке; требуется аккуратное объединение с Host Studio, включая его новые фильтры, отчёты и тесты. Основная ветка и публичный сайт не перезаписывались. Canva-демо готово. APK этой ревизии не собран и не подписан.

Автоматический npm audit выявил 3 moderate-записи в одной цепочке сборочных зависимостей: undici -> miniflare -> wrangler, GHSA-3wwx-pv8p-q78v. Это не исправлено в этой ревизии. Не запускать npm audit fix --force без проверки совместимости; не утверждать, что уязвимостей нет.

Реальные платежи/выплаты, авторизация, общая база, синхронизация площадок и реальные сообщения гостям остаются неподключёнными. Данные Canva сбрасываются после обновления страницы. JARVIS не затронут.

Для реального пилота нужны актуальные доступность и тарифы выбранных объектов, правила отмены/предоплаты/депозита и матрица доступа сотрудников и собственников. Секреты, коды дверей и платёжные ключи не включать в публичные файлы.
